02 / 目標與流程

七個設計步驟，共用同一個目標

步驟關鍵問題應留下的設計結果
1. 確立學習目標完成後，學生能做什麼？可觀察的表現與達成標準。
2. 分析學習者特徵學生已會什麼？需要什麼支持？先備知識、能力差異、興趣與數位操作需求。
3. 選擇核心機制什麼玩法能練習目標能力？任務、規則、限制、互動及勝敗條件。
4. 嵌入學習內容玩家如何運用知識完成任務？概念、技能與遊戲行動的對應。
5. 設計回饋與獎勵學生如何知道問題並調整？回饋內容、提示時機與獎勵規則。
6. 測試與調整規則是否清楚？難度是否合適？試玩觀察與修訂紀錄。
7. 評估學習成效有什麼證據顯示達成目標？測驗、實作、歷程、反思或觀察資料。

第一步最關鍵：學習目標決定後續設計方向，也是最後評量的依據。流程可反覆修正；列在最後的評量，在設定目標時就應一併思考如何蒐集證據。

一、用 SMART 檢查目標

Specific 具體、Measurable 可衡量、Achievable 可達成、Relevant 相關、Time-bound 有時限。

整理者補充例｜標準須依課程調整

完成本次 40 分鐘活動後，學生能在五個新情境中，正確選擇至少四個適當的混合物分離方法，並說明所依據的物質性質。

二、把教育語言轉成玩家任務

學習目標：預期能力遊戲目標：玩家任務
根據物質性質，規劃混合物分離流程。在有限資源內，為基地完成指定物質的回收任務。
說明選擇依據，並根據結果修正方法。判讀操作結果，找出失敗原因並調整下一次方案。
複習提醒：遊戲目標與學習目標是不同層次的目標；兩者要對應。講義所稱「隱性學習目標」是融入玩法的設計方式，不表示必須對學生隱瞞學習目的。

03 / 內生與外生整合

觀察「知識」和「玩法」的連結

比較面向外生整合內生整合
結構學習活動外附加獎勵或遊戲包裝。知識的規律、限制或技能構成玩法。
操作例子答對一道題，角色獲得一次攻擊機會。運用角度與力道判斷，決定物體的移動結果。
替換學科通常較容易更換題目而保留玩法。更換學科常需要重新設計規則。
設計優勢容易加入既有教材，開發成本較低。操作與學科思考緊密對應。
應檢查的問題學生是否只追求獎勵、猜題或速度？學生能否說明概念，並在遊戲外應用？

一、內生整合的四個設計方法

1. 因果映射：把學科規律轉成遊戲環境的運作規則，讓玩家從行動與後果理解因果關係。

2. 決策張力與資源限制：把學科中的權衡轉成策略選擇。例如玩家必須比較不同方案的成本、效率與結果。

3. 漸進進程與鷹架：逐步引入新概念，提供可理解的失敗回饋，使學生能修正策略後再挑戰。

4. 反思與抽象遷移：回顧遊戲歷程，說明所用概念，再安排新情境任務，檢查學生是否能運用。

遊戲操作 → 看見後果 → 修正策略
↓
說明概念 → 連結學科語言 → 應用於新情境

二、三個融合檢查問題

  1. 玩家哪一個行動，正在練習預期的知識、技能或態度？
  2. 如果更換學習內容，哪些核心規則也必須跟著改變？
  3. 玩家成功後，能否解釋原理，而不只是重複過關操作？
解讀界線｜整理補充：內生與外生整合是分析設計的角度，不宜直接當成成效高低的結論。外生設計不一定無效，內生設計也不保證理解或遷移；必須看目標、實際設計與評量證據。

04 / KSA 與完整設計例

不同學習目標，需要不同任務

目標類型如何融入遊戲應蒐集的學習證據
知識 K
Knowledge		把概念做成解謎線索、資源或環境規則；玩家需要理解概念才能作決策。辨識、解釋、比較與新情境應用。
技能 S
Skills		讓核心操作包含反覆練習、即時結果與策略修正。操作正確性、獨立完成程度、錯誤修正。
態度 A
Attitudes		透過角色立場、有後果的選擇、情感經驗與合作。選擇理由、反思、互動表現與態度測量。

補充：KSA 是目標類型；Bloom 的記憶、理解、應用、分析、評鑑、創造是認知歷程層次。兩者不宜一一對號。合作可以涉及技能與態度；問題解決也不能一概歸為態度。

05 / 回饋、難度與自我調節

回饋要提供下一步的行動線索

挑戰 → 表現紀錄 → 判讀成功／失敗
成功：檢查精熟程度 → 安排適當的新挑戰
失敗：診斷原因 → 給予提示 → 調整策略 → 再挑戰

獎勵能標示進展與成就；具有學習功能的回饋，則應幫助學生知道表現、問題與修正方向。AI 可協助分析作答或操作歷程，提供不同程度的引導。

一、把「答錯了」變成可使用的提示

回饋層次以規劃任務為例的提示
指出結果「這個流程未能達成回收目標。」
引導自我檢查「哪一步的結果和你的預測不同？」
聚焦關鍵概念「請比較這兩種物質的性質；你目前的操作利用了哪個差異？」
安排再應用「請調整一個步驟，預測改變後的結果，並說明理由。」

上表提示為整理者補充例。提示應隨需要提供；學生熟練後逐步減少支持，並檢查無提示時的表現。

二、最終目標：自我調節學習（SRL）

學生逐漸學會監控自己的表現、分析錯誤、調整策略及主動尋求協助。持續得到正確答案，不等於已具備自主修正能力。

三、把設計機制連回學習理論

理論本課程的設計連結
建構主義從操作、互動、先備知識與反思中建立理解。
心流理論讓挑戰與能力相互配合，持續調整難度。
鷹架／最近發展區提供適當支持，協助完成尚無法獨立完成的任務。
自我決定理論關注自主感、勝任感與關係感，設計選擇、進展與互動。
情境學習／社會建構在有意義的情境中應用知識，透過合作與討論形成理解。
解讀提醒：AI 診斷、適性難度與提示是待檢驗的介入設計。是否診斷正確、是否促進學習，都需要證據；加入 AI 本身不代表成效已提升。

06 / 變項與操作型定義

想測的能力，要轉成看得見的證據

學習目標 → 界定研究構念 → 決定測量方式與指標
例如：能解決問題 → 問題解決能力 → 新情境任務的規準評分
名詞意思本講義研究例
自變項 IV研究操控或比較的條件。AI 診斷式提示／固定提示。
依變項 DV研究要觀察的結果。問題解決表現、學習動機。
操作型定義明確規定如何觀察、測量及計分。新情境任務中，依規準評定問題分析、方案理由與修正品質。
中介變項模型中用來說明介入如何影響結果的過程。假設自我調節學習是提示影響問題解決表現的中介。

一、主要、次要與中介，不是固定身分

主要依變項對應研究的核心目的；次要依變項是同時關注的其他結果。若研究目的就是改善學習動機，動機可以是主要依變項。

中介變項有特定的模型角色。例如「提示方式 → 自我調節學習 → 問題解決表現」是待檢驗的作用路徑。不能因為三者都有變化，就認定中介關係成立。

二、常見測量與其界線

想了解的成果可考慮的資料解讀時注意
概念理解解釋題、概念應用題。答對可能來自猜測；可搭配理由判讀。
技能與遷移新情境實作、無提示任務。熟悉原遊戲，未必能處理新任務。
學習動機適合對象的量表、訪談。自陳感受與實際行為不完全相同。
學習歷程提示使用、決策路徑、修改紀錄。點擊次數本身不等於思考深度。

07 / 探索、驗證與假設

先決定想發現什麼、檢驗什麼

面向探索性研究驗證性研究
目的發現現象、模式與可能的解釋。檢驗已有理論或文獻支持的推論。
問題例學生失敗時，如何使用提示？出現哪些修正策略？AI 診斷式提示是否提升問題解決表現？
常見資料訪談、觀察、歷程及探索性統計。實驗或準實驗資料、量表與模型檢驗。
產出概念、可能關係、待驗證假設。推論獲支持或未獲支持的證據。

研究類型由目的與設計決定，不能只看「如何／是否」，也不能直接等同質性／量化。文獻探討可協助建立架構，但不等於探索性研究。

一、兩種研究進路

探索導向：發現問題 → 蒐集資料探索 → 建立概念或模型 → 提出假設 → 驗證。

文獻導向：發現問題 → 整理既有理論與研究 → 建立架構與假設 → 蒐集資料驗證。

研究不一定都要先進行探索。已有足夠理論與文獻時，可以形成明確假設後進入驗證；兩種取向也能互相補充。

二、把寬泛問題縮成可研究的比較

由「這個遊戲有沒有效？」縮小為：

研究問題示例｜整理者補充

在相同學習內容與遊戲任務下，接受 AI 診斷式提示的學生，相較於接受固定提示的學生，是否有較佳的新情境問題解決表現？

對應假設：AI 診斷式提示組的新情境問題解決表現高於固定提示組。這是研究前提出的預期，尚未代表結果成立。

三、設計研究時的基本檢核

  • 比較清楚：兩組究竟差在提示內容、提示時機，還是多個條件同時不同？
  • 背景可比較：記錄先備能力、學習時間及教師支持等可能影響結果的因素。
  • 測量對齊：若主張遷移，就要安排新情境；若主張保留，就要安排適當的延宕測量。
  • 解釋有界線：顯著差異不直接等於效果大；因果解釋需配合研究設計，不能只依相關或前後變化。

08 / 情意、社交與設計品質

體驗之後，安排反思與遷移

一、情意與社交學習的四個設計重點

設計原則實作方向
角色代入讓玩家從不同立場作決策，說明感受、理由與價值取捨。
有意義的選擇選擇會改變資源、關係或後續情境，讓玩家看見後果。
相互依賴的合作分配互補資訊、能力或角色，使溝通與協調成為完成任務的必要條件。
可安全嘗試的空間允許失敗、回顧與再試，讓學生能修正決策與互動方式。

教師的反思提問：「你為什麼這樣選？」「哪個資訊改變了你的判斷？」「合作卡在哪裡？」「換到生活中的類似情境，你會怎麼做？」

原講義把「體驗的建構」視為建構主義在遊戲情境中的實踐與延伸。本講義依此理解，不把它當成已獨立建立的新理論。

10 / 自我校正

參考解答

1｜核心融合：玩家為了完成任務所做的操作與思考，同時練習目標能力。例如撰寫與除錯程式，控制機器人通過迷宮。
2｜七步驟：確立目標、分析學習者、選擇核心機制、嵌入內容、設計回饋與獎勵、測試調整、評估成效。目標決定任務與評量方向。
3｜整合判讀：甲較接近外生整合；乙在資源規律直接構成玩法時，較接近內生整合。僅依類型不能判定成效，仍須檢查實際學習證據。
4｜引導提示：例如先問「哪一步的結果與預測不同？」再問「你選擇這個操作時，利用了哪些條件或性質？」重點是協助檢查與修正，而非只重複對錯訊息。
5｜變項與測量：自變項是提示方式；主要依變項是問題解決表現。操作型定義可為新情境任務中，以固定規準評定問題分析、方案理由與修正品質的得分。
6｜兩個修正：主要與次要依變項由研究目的決定，動機也能是主要依變項。已有充分理論與文獻時，可直接建立假設並設計驗證研究。
7｜合作機制：同組不足以保證合作。可分配互補資訊，讓成員需要交換資訊才能決策；評量可觀察資訊分享、協調與共同修正的表現。
8｜遷移證據：安排不同情境或遊戲外的任務，檢查能否獨立應用並說明理由。若關注保留，再安排適當的延宕測量。
