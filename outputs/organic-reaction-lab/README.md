# 反應分流局：整合學習課程

原生 HTML／CSS／JavaScript 與 Python 標準函式庫，本機執行不需套件、CDN、帳號或 API 金鑰。原 index.html 與 academy.html 已共用同一入口；不再保留兩套教學或獨立六關。

## 本機啟動

本資料夾執行：

```sh
python3 server.py
```

Python 3.10 以上。開啟 http://127.0.0.1:8768/academy.html 。原 http://127.0.0.1:8768/index.html 會使用符合既有 CSP 的 entry.js 轉至相同介面，保留查詢與錨點。若連接埠占用可執行：

```sh
python3 server.py --port 8770
```

```sh
curl http://127.0.0.1:8768/health
```

伺服器只綁 loopback，只提供白名單資源及指定原文頁。必須透過 HTTP 使用 ES modules，不能直接雙擊 HTML。沒有發布、commit 或 push。

## 學習流程與內容配置（漸進交錯版，2026-10-26）

對象為大一有機入門、尚無反應機構概念的學生。目標是看到受質、試劑與條件後，能選出反應類型、說出判斷依據、預測產物並畫出電子箭頭。主程式為 learning-path.js（介面）與 course-path.js（內容）。

採暖色小島探險風的地圖，學習畫面維持同色系的乾淨版面。保留暖身→五階段→總混合練習→選做評量；遊戲化留待後續加入。

- 頁首「學生／教師」手動切換並保留目前單元、概念與階段步驟。學生模式沿用原有作答與進度。

- 教師示範使用獨立的記憶體練習狀態，不寫入學生的預測、答案、首次判斷、精熟度或觀看書籤。切回學生只帶回課程位置；重新整理不保存教師練習答案。教師模式的選做評量入口可切回學生模式，不直接顯示學生成績。學生評量進行中停用模式切換。
- 桌機預設三維／書面式並排；手機預設單一大圖，可切換「三維／書面式／上下對照」，共用同一段落與進度。顯示方式、球棍／軌域與連續播放選項隨學生觀看書籤保存。
- 每個實際機構步驟的結構完成時自動暫停，按「繼續下一步」觀察後續；可勾選「連續播放」。SN2／E2 的逐支電子箭頭只是解說焦點，不額外建立中間體或自動停點。

## 三維與畫面操作

- 固定對照視角：三維與書面式共用投影基準，Br、Cβ、取代基與試劑的相對方向一致。按模型上方「對齊視角」可從自由旋轉返回；播放前也會回到此視角。書面式保留 120° 平面整理與楔形鍵，不跟隨自由拖曳。舊書籤的預設鏡頭會更新為共同視角，自訂鏡頭、段落與進度保留。
- 模型上方可切換「球棍模型／混成軌域」，模式隨觀看書籤保存。混成軌域只畫反應中心碳：sp³ 大小葉瓣、sp² 的三個混成方向與一個未混成 p 軌域；碳陽離子標空 p，烯顯示兩個碳的 p 軌域。軌域隨模型旋轉；成斷鍵途中以兩端模型交淡，不把過渡態指定為單一混成。顏色區分軌域相位，並非電荷；形狀及大小是教學模型。
- 書面結構式以固定教科書視角顯示，試劑接近、離去及原子位置隨同一進度連續更新，彎箭頭與孤對電子跟隨位置。立體鍵以實心楔形朝前、虛線楔形朝後，依三維構形的有向體積配置；平面中心不顯示楔形；三配位碳陽離子與烯的 sp² 中心逐漸排成約 120°，重新成為四面體時恢復立體鍵。小環受環形幾何限制，不強迫拉成理想 120°。手機原子標示至少 14px，產物文字以 HTML 顯示，避免隨整張結構圖縮小。拖曳只旋轉三維模型，書面視角保持可讀。切到產物時不再跳位。
- 暖身「數級數，找 α 碳與 β 碳」新增 2-溴丁烷圖解：標出 α／β 碳與 β-H，並比較甲基、一級、二級與三級。窄螢幕的結構圖可左右滑動，保留可讀字級。
- 試劑整體接近反應部位，電子對沿曲線移動，原鍵淡出、新鍵淡入；分段解說不代表增加中間體。
- 播放、暫停、上一段／下一段、重播及進度條常顯。旋轉／縮放先暫停，操作只改攝影機。
- 手機水平拖曳旋轉、垂直捲頁。放大使用同一播放器的 dialog，返回保留段落及焦點；Esc 可返回。
- 引導片段及完整例子使用不同觀看書籤，返回課程／重載均可保留段落、進度與鏡頭，還原固定暫停。
- 動畫關鍵標籤與課內／評量三維標籤維持實際 14px。課內模型標籤有引線與避讓；Newman 說明使用 HTML 文字。
- 完整解說、視角設定、原文頁碼與中英術語按需展開。不同觀察與檢核工具一次只掛載一個。
- Me＝CH₃；評量／檢核模型採反應中心縮合表示。動畫採 XYZ 球棍與深度排序，但所有座標及插值均為教學幾何，非實測電子軌跡、量子化學或分子動力學。

## 評量

選做後測／延後測各 10 題、100 分，涵蓋九種反應類型，起始物都是課程與題庫沒出現過的分子（遠遷移；單元測試會檢查）。每題：反應類型 3、依據 2、產物 2、電子箭頭 3 分。箭頭依學生所選類型提供模板，類型選錯時箭頭不計分。評量中沒有 AI 或正誤提示，提交後顯示逐題對照。紀錄版本 path-assessment-v3，每次提交使用獨立鍵 `organic-assessment-v3:attempt:<id>`。題本尚未經學生試測校準，分數變化不代表 AI 或三維功能的因果效果。

### 獨立比較動畫模組（尚未接入課程）

`comparisons.js` 匯出四組 `COMPARISONS`，以及供測試使用的純函式
`comparisonScene(id, 'winner' | 'loser', progress)`；進度範圍為 0–1。
`comparison-view.js` 匯出 `comparisonHTML(id)` 與 `mountComparison(root)`。
整合時由宿主載入 `comparison.css`，把 HTML 放入 DOM 後呼叫掛載函式；
它接受單一比較 section 或含多組比較的容器，回傳可重複呼叫的 cleanup。
替換課程內容前呼叫 cleanup；重新掛載同一 section 也會先清理舊掛載。
未知 id 會拋出 `RangeError`，不以其他比較代替。

- 四組 id：`primary-sn2-vs-sn1`、`tertiary-sn1-vs-sn2`、
  `bulky-e2-vs-sn2`、`heat-e1-vs-sn1`。
- 一次同步播放共 9 秒，按同一按鍵可暫停／繼續／重播；不自動播放。
  系統減少動態或 `body[data-art-motion="paused"]` 直接顯示終態／嘗試關鍵幀。
  離屏、頁面隱藏、移除 DOM 或 cleanup 都取消 RAF，返回時不自動續播。
- 輸的路保留反應物的連接；加熱組只允許共同的第一步離解，分岔後不形成
  C–O 鍵。乙醇與碳陽離子沿用 E1 幾何，避免把富水環境的 SN1 例子誤作乙醇。
  SN1 仍可競爭，右側停止成鍵只是比較呈現方式。
- 1-溴丁烷只有一個 β 碳，產物為 1-butene；此例不能證明 Hofmann／Zaitsev
  區位偏好。能量圖全部為定性示意，加熱組保留共同第一步的相同能障，
  不由熵推算活化能或產物比例。
- 不更動既有 `energyHTML()`；新增的 `comparisonEnergyHTML()` 由比較畫面使用。
