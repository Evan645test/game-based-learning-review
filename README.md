# 遊戲式學習｜知識脈絡圖與 100 題練習

繁體中文課程複習工具，包含可點選的知識脈絡圖、100 題是非練習，以及 10 頁重點講義。

## 使用方式

- 線上入口：https://Evan645test.github.io/game-based-learning-review/
- 離線使用：下載 [複習資料包](outputs/遊戲式學習_複習資料包.zip)，解壓縮後開啟「遊戲式學習_知識脈絡圖.html」。
- 完整講義：[HTML 閱讀版](outputs/遊戲式學習重點複習/遊戲式學習_重點複習講義.html)／[PDF 列印版](outputs/遊戲式學習重點複習/遊戲式學習_重點複習講義.pdf)。

## 功能

- 16 個概念節點，涵蓋學習目標、遊戲設計、學習歷程及成效證據。
- 點選節點、概念清單或搜尋結果，直接跳到對應內容；另支援圖面縮放與相關概念跳讀。
- 100 題是非題（50 是、50 非），作答後提供詳解、概念與講義頁碼連結。
- 全部、未作答與錯題複習；單題重答、優先複習建議及返回原題。
- 原第 1–50 題維持編號、題目與答案；第 51–100 題增加情境判讀及設計應用。
- 鍵盤操作、可見焦點與減少動態效果的支援。

作答進度儲存在目前瀏覽器的 localStorage，沒有帳號或雲端同步。更換瀏覽器、網站來源或檔案位置可能無法沿用；本機作答紀錄不會自動移到網站。無法使用儲存功能時，仍可在本次開啟期間作答。

## 檔案與部署

網站使用原生 HTML、CSS 與 JavaScript，不需要套件安裝、API 金鑰、資料庫或建置工具。

- `index.html`：網站入口，導向複習頁面。
- `outputs/遊戲式學習重點複習/`：知識圖、題庫、講義與說明；請維持檔案相對位置。
- `outputs/遊戲式學習_複習資料包.zip`：四個閱讀檔案的離線資料包。
- `.nojekyll`：讓 GitHub Pages 直接發布靜態檔案。

GitHub Pages 的發布來源為 `main` 分支根目錄。更新閱讀檔案及 ZIP 後，推送至 `main` 即可觸發網站更新。預覽時可直接用瀏覽器開啟 `index.html`；也可在專案根目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。
